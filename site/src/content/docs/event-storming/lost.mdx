<p class="lead">次に何をすればよいか分からなくなったら、チャットの入力欄の **ガイド**（コンパスのアイコン）を押すか、`/guide` を送ります。だれが押してもかまいません。</p>

## ガイドのカード

<StepsBeside shot="guide-card" alt="ガイドのカード" caption="ガイドのカード（例外の段階まで進んだストーミング）">

1. **地図**　いまのジャーニーの、ブリーフからゴールまでの道のり。済んだ段階に ✓、いまの段階に 📍、ゴールに 🏁。ゴールの先の段階は薄く描かれる。済んだかどうかはファイルから決まり、AI の判断ではない。カードの見出しのジャーニー名を押すとジャーニーのパネルが、🏁 を押すとゴールの選択が開く。
2. **すぐ分かること**　ボタンを押した瞬間に、ファイルから機械的に分かること。例外のない段階、開いた問い、長すぎる名前、`dt check` の指摘。各行の「見る」「図で見る」でその場所へ行く。
3. **AI の助言**　数秒後に届く。いまの状況と、次の一歩を1〜3つ。それぞれに理由、コマンドのボタン、見る場所、「聞くことをメモ」が付く。

</StepsBeside>

- コマンドのボタンは、そのコマンドを入力欄に入れるだけです。送るのは人です。
- ガイドが勧めたコマンドには、`/` の一覧で ⭐ が付きます。
- ブリーフがまだないと、地図は「ゴールを決める」だけです（[ブリーフ](../workshop/brief/)）。
- 最新のカードは、ジャーニーファイルのいまの状態を描きます。古いカードには「これより新しいガイドがあります」と出ます。

## ✓・📍・未確認

| 印 | 意味 |
|---|---|
| ✓ | 済んだ段階。ファイルから決まる |
| 📍 | いまの段階：済んだ最後の段階の、次の段階 |
| 未確認 | 📍 より前で、まだ済んでいない段階。ファイルからは決められず、だれも「済み」にしていない |
| 🏁 | ゴール。ゴールの先は薄く描かれる |

「例外」と「問い」は、ファイルだけでは決めきれないことがあります（例外の要らない段階、問いの出なかったストーミング）。そういう段階の下には**チェックボックス**が付き、チェックすると「済み」、外すと「済みにする」に戻ります。チェックはジャーニーファイルに残ります。

- コラボでは、参加者のチェックはファシリテーターへのお願いになり、承認されると付きます。
- だれが何を済みにしたかは、チャットに記録として残ります（[チャットの記録](#チャットの記録)）。

## チャットの記録

ゴールを変えた、済みにした、ジャーニーを完了にした・しまった・戻した、いまのジャーニーを替えた、といったことは、チャットに小さな行で残ります（例：「田中 がゴールを ビッグピクチャー → デザインレベル に変えました」）。コラボでほかの人が何をしたか、あとから分かります。

- 参加者のお願いは、その行に結果が書き足されます（「…お願いしました。佐藤 が承認しました」）。
- 続けて済みにしたものは、1行にまとまります。
- git などでジャーニーファイルが外で変わったときも、何が変わったかが1行で出ます。

## よくある迷い

| 迷い | 見るところ |
|---|---|
| 出来事がこれで足りているか | `/es:gaps`、ブリーフの最初と最後の出来事 |
| どこまでやればよいか | アプリバーのいまのジャーニーのチップ（🏁 のゴール） |
| 議論が終わらない | 問いとして残す（[問い](../workshop/questions/)） |
| 付箋の名前がばらばら | `/es:names` |
| 画面がごちゃごちゃする | 段階のビュー、絞り込みで例外を隠す |
