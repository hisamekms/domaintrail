<p class="lead">次に何をすればよいか分からなくなったら、チャットの入力欄の **ガイド**（コンパスのアイコン）を押すか、`/guide` を送ります。だれが押してもかまいません。</p>

## ガイドのカード

<StepsBeside shot="guide-card" alt="ガイドのカード" caption="ガイドのカード（例外の段階まで進んだストーミング）">

1. **地図**　ブリーフからゴールまでの道のり。済んだ段階に ✓、いまの段階に 📍、ゴールに 🏁。ゴールの先の段階は薄く描かれる。済んだかどうかはファイルから決まり、AI の判断ではない。
2. **すぐ分かること**　ボタンを押した瞬間に、ファイルから機械的に分かること。例外のない段階、開いた問い、長すぎる名前、`dt check` の指摘。各行の「見る」「図で見る」でその場所へ行く。
3. **AI の助言**　数秒後に届く。いまの状況と、次の一歩を1〜3つ。それぞれに理由、コマンドのボタン、見る場所、「聞くことをメモ」が付く。

</StepsBeside>

- コマンドのボタンは、そのコマンドを入力欄に入れるだけです。送るのは人です。
- ガイドが勧めたコマンドには、`/` の一覧で ⭐ が付きます。
- ファイルから判断できない段階は、ファシリテーターが ✓ を付けたり外したりします。
- ブリーフがまだないと、地図は「ゴールを決める」だけです（[ブリーフ](../workshop/brief/)）。

## よくある迷い

| 迷い | 見るところ |
|---|---|
| 出来事がこれで足りているか | `/es:gaps`、ブリーフの最初と最後の出来事 |
| どこまでやればよいか | アプリバーの旅のチップ（🏁 のゴール） |
| 議論が終わらない | 問いとして残す（[問い](../workshop/questions/)） |
| 付箋の名前がばらばら | `/es:names` |
| 画面がごちゃごちゃする | 段階のビュー、絞り込みで例外を隠す |
