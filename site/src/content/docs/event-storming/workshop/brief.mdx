## 進め方

<StepsBeside shot="interview-choice" alt="聞き取りの質問と、答えの選択肢（ストーミングを名前で選ぶ）" caption="/es:start の質問。選択肢を押すとそのまま答えになる">

1. **`/es:start` を送る**　チャットで `/` を打ち、「ES を始める」を選ぶ。参加者が始めてもよい。入力欄の上に「聞き取り中」のバーが出る。
2. **質問に答える**　AI が1つずつ聞く。選択肢が出たら押す。ストーミングは ID ではなく名前（「住民票のコンビニ交付」）で並ぶ。複数選べる質問はチェックして「送る」。合わないときは「その他（自分で書く）」で入力欄に書く。
3. **ゴールを選ぶ**　「どこまで進めますか」も選択肢で聞かれる。**Big Picture** か **デザインレベル** を押す。
4. **あいまいさを詰める**　答えがあいまいだと、AI がさらに聞く。ワークスペースに書いてあることは聞かれない。

</StepsBeside>

<StepsBeside shot="brief" alt="聞き取りのバーに出たブリーフと、確定・編集して確定・中止" caption="最後に出るブリーフ。目的・範囲・参加者と、ゴール・使い道">

**5. ブリーフを確かめる**　最後に AI がブリーフをまとめ、聞き取りのバーに出す。ファシリテーターが **確定** か **編集して確定**。参加者が始めたものは、ファシリテーターが **承認**・**編集して承認**・**却下**（理由を添えられる）。確定する代わりにメッセージを送ると、質問に戻る。

**6. お知らせを読む**　確定すると、dt が聞き取りの最後に**お知らせ**を書く（AI は呼ばない）。何を決めたか、いまどの段階か、次に何をするか。次のコマンドのボタン（入力欄に入るだけ）と「ジャーニーを開く」が付く。

</StepsBeside>

<StepsBeside shot="completion-note" alt="確定のあとのお知らせ：ジャーニーに加えたこと、いまの段階、ジャーニーを開く" caption="確定のお知らせ。いまは「流れ・段階」の段階と分かる">

- 出来事がまだないストーミングなら、「まず出来事を出します。起きたことを話してください。」と出ます。
- 新しいストーミングは、AI の作業でストーミングが作られたあとにお知らせが出ます。
- ブリーフを見直したときは、変わった項目がお知らせに出ます。

</StepsBeside>

## ブリーフに入るもの

| 項目 | 例 |
|---|---|
| 目的 | いまの流れを知る／良くする／新しく設計する |
| 範囲 | 住民票を頼まれてから、提出先に受け取ってもらうまで |
| 使い道 | 認識をそろえる（`align`）／モデリングへつなげる（`modeling`） |
| ゴール | Big Picture（問いまで）／デザインレベル（その先まで） |
| 参加者 | 窓口担当、申請者 — **役割で書く**。人の名前は書かない |

ブリーフは、ワークスペースの**ジャーニーファイル** `domaintrail.journey.json`（`domaintrail.jsonc` の隣にある、git で管理するファイル）に、ストーミングごとの**ジャーニー**として残ります。書くのは dt だけで、AI は読むだけです。ゴールを変える、済みにする、完了にするのも、聞き取りなしで画面からできます。git やほかの道具でファイルが変わっても、すぐ画面に出ます。ストーミングの `///` は短い説明だけです。

## いまのジャーニーを見る

<StepsBeside shot="journey-panel" alt="ジャーニーのパネル：ブリーフ、地図、完了にする・ゴールを変える・ブリーフを見直す・しまう・ガイドを見る" caption="チップを押すと開くジャーニーのパネル">

アプリバーの、「ドメインモデル｜イベントストーミング」の切り替えの右に、**いまのジャーニーのチップ**が出ます：`🧭 住民票のコンビニ交付 · 📍 流れ・段階 → 🏁 ビッグピクチャー`。ゴールに着くと 🏁 に「✓ 到達」が付きます。ジャーニーがないときは「🧭 ゴールを決める」です。

チップを押すと**ジャーニーのパネル**が開きます。

- いまのジャーニー：ブリーフ（目的・範囲・参加者・使い道）と地図、**完了にする**、**ゴールを変える**、**ブリーフを見直す**（入力欄に `/es:start` が入る）、**しまう**、**ガイドを見る**
- ほかのジャーニー：それぞれどこまで来たか。「このジャーニーにする」でいまのジャーニーを替える
- 新しいジャーニー（`/es:start`・`/model:start`）と、しまったジャーニー（「戻す」で戻せる）

</StepsBeside>

- セッションのいまのジャーニーは1つです。コラボではファシリテーターが決め、全員が同じジャーニーを見ます。パネルはだれでも読めます。
- 参加者がゴールを変える・済みにする・完了にする・しまう・ジャーニーを替えると、ファシリテーターへの**お願い**になります。ファシリテーターはパネルで **承認** か **却下**、お願いした人は **取り下げ** できます。
- 図でストーミングを選ぶと、詳細にもそのジャーニーの目的・いまの段階・ゴールが短く出ます。

## AI はジャーニーの中で動く

AI の答え・コマンド・聞き取り・付箋を書く作業は、どれもいまのジャーニーを知っています。ジャーニーの範囲とゴールの外に出るときは、先に聞きます。たとえば Big Picture のストーミングに、頼まれていないのにコマンドや集約を書くことはありません。ゴールを変えたら、AI もそれに合わせます。

:::tip[コツ]
「最初の出来事」と「最後の出来事」が答えられれば、範囲は決まります。聞き取りでも必ず聞かれます。
:::

:::caution[よくあるつまずき]
ゴールを欲張らない。初回は Big Picture で十分です。Design Level は、流れに合意できてから別の回で行います。
:::
