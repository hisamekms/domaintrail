## 進め方

<StepsBeside shot="export-menu" alt="ビューバーの書き出しメニュー" caption="ビューバーの右端の「書き出し」">

1. **ふり返る**　`/es:recap` を送る（だれでもよい）。AI がセッションから「決まったこと」「追加・変更」「未決」をまとめる。
2. **残す**　ビューバーの **書き出し** から、印刷、PDF（印刷画面から保存）、PNG、SVG。「見出しを含める」「凡例を含める」も選べる。画面と同じビュー・同じ絞り込みで出る。
3. **ソースを渡す**　リポジトリのない人には、メニューの「ソース一式をダウンロード」か `dt export sources`（ZIP）。
4. **ジャーニーを完了にする**　ゴールに着くとチップに「✓ 到達」が付き、ガイドが「完了にする」を勧める。アプリバーのチップから開くジャーニーのパネルで押す。dt がチャットにお知らせを書き、次の一歩（使い道が「モデリングへつなげる」なら `/model:start`、「認識をそろえる」なら `/es:recap`）のボタンが付く。
5. **コラボを終える**　メニューの **コラボを終える**。終わっていない作業があれば一覧が出る。終えると、変更・参加者・時間のまとめが全員の画面に出る。

</StepsBeside>

## モデリングへ渡す

ブリーフの使い道が「モデリングへつなげる」なら、ゴールに着いたときガイドが `/model:start` を勧めます。最初の選択肢は **B. ES から**（このストーミングから）です。

| B. ES から の道のり | すること |
|---|---|
| ストーミングを見直す | 流れ・例外・問いを読み直す |
| 境界づけられたコンテキストを切り出す | ストーミングから BC を分ける |
| 集約 | デザインレベルの集約を `.dt` の集約にする |
| コマンドとイベント | `.dt` に書き、ストーミングに `ref` を付ける |
| 不変条件 | 守るべき決まりを書く |

- `/model:start` は、続けるジャーニーを選ぶか、新しいジャーニーを名前を付けて始めるかを最初に聞きます。ストーミングは選択肢に名前で並びます。
- 確定すると、モデリングのジャーニーがジャーニーファイルに加わり、いまのジャーニーになります。ES のジャーニーには、パネルの「このジャーニーにする」で戻れます。
- ストーミングから `.dt` のモデルへ進むのはモデリングです。ストーミングは `.dt` ファイルを変えません。

:::tip[コツ]
印刷は横向き1枚に収まります。壁に貼るなら、絞り込みで例外を隠した全体と、段階ごとのビューを1枚ずつ。
:::

:::caution[よくあるつまずき]
ストーミングを清書しない。疑問や開いた問いも、見つけたことの記録です。きれいに見せるために問いや出来事を消さないでください。
:::
