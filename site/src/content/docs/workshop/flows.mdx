## 言葉

| 言葉 | 意味 | 例 |
|---|---|---|
| 段階（stage） | 流れの時間の区切り。前の段階のあと（`after`）に続く | 依頼・準備 → コンビニでの発行 → 提出 |
| 本流 | 段階の最初の流れ。一直線に描かれる | コンビニに行った → … → カードを回収した |
| 別の通常の流れ | 本流から分かれる、もう1つのいつもの道 | 調べてから行く |
| グループ | 同時に起きる、順番のない出来事 | — |

## 進め方

<StepsBeside shot="view-switch" alt="ナビゲーターとビューバー：ストーミング › 段階 › 流れ" caption="ナビゲーターとビューバーは、いつも同じ選択を指す">

1. **いつもの流れを話す**　「まず〜して、次に〜」と最初から最後まで。AI が流れにする。
2. **段階に分ける**　流れが長いときは、切れ目を話す。AI が段階を作り、順に `after` でつなぐ。
3. **ビューを切り替えて確かめる**　左のナビゲーターでストーミング › 段階 › 流れを選ぶ。ビューバーのパンくずも同じ選択を指す。「すべて（統合）」は全体、段階を選ぶとその段階だけ。
4. **間を埋める**　`/es:gaps` を送る。隣り合う出来事の間に抜けている出来事が候補に出る。

</StepsBeside>

:::tip[コツ]
「調べてから行く」のような別のいつもの道は、例外ではなく別の流れです。分かれる出来事から書き始めると、本流から枝分かれして描かれます。
:::

:::caution[よくあるつまずき]
流れは「この順に起きることがある」という並びで、原因と結果ではありません。失敗や寄り道を本流に混ぜると、一直線に読めなくなります。それは次の章で例外として出します。
:::
