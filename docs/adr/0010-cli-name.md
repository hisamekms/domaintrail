# ADR 0010: CLI name

- Status: accepted
- Date: 2026-10-18

## Context

The CLI was installed as `dmtr`, an abbreviation of domaintrail that is neither short to type nor easy to remember.
The package has not been published yet, so the name can still change without breaking anyone.

## Decision

- **`dt`** is the command for everyday use, matching the `.dt` file extension. The README, help, error messages and
  generated headers write commands as `dt …`.
- **`domaintrail`**, the package's name, is installed alongside it as the full name, for when `dt` clashes with
  another command or a script should spell it out (CI, for example). Both run the same entry point (`dist/dt.js`).
- **`dmtr` is dropped** with no alias, since it was never published.

## Consequences

- `npx domaintrail <command>` works without installing, and `npx dt <command>` once the package is installed.
- Files generated with the old header (`run \`dmtr generate ts\``) are still recognized as generated: the marker
  that identifies them, `// Generated by domaintrail.`, is unchanged.
